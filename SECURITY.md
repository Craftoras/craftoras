# Security Policy

## Supported Versions

We actively maintain and provide security updates for the latest release on the default branch.

| Version | Supported          |
| ------- | ------------------ |
| main    | :white_check_mark: |
| < 1.0   | :x:                |

## Reporting a Vulnerability

The Craftoras team takes the security of our platform and user data seriously. If you discover a security vulnerability, we appreciate your help in disclosing it to us responsibly.

### How to Report

Please **do not** disclose security vulnerabilities publicly through GitHub issues, discussions, or social media until they have been addressed.

Instead, please report security issues using one of the following methods:

1. **GitHub Private Vulnerability Reporting (Preferred)**:
   Navigate to the repository's [Security Advisories](https://github.com/Craftoras/craftoras/security/advisories) tab and click **"Report a vulnerability"**.

2. **Email**:
   Send an email to [security@craftoras.com](mailto:security@craftoras.com) (or contact the maintainers directly via [darrehanrasool](https://github.com/darrehanrasool)).

### What to Include in Your Report

To help us triage and resolve the issue quickly, please include:
* A detailed description of the vulnerability.
* Clear steps to reproduce the issue (proof of concept scripts, screenshots, or sample requests).
* Potential impact and attack scenarios.
* Any suggested remediation or patches, if available.

### What to Expect

* **Initial Response**: We will acknowledge receipt of your vulnerability report within 48 hours.
* **Triage & Assessment**: We will investigate and validate the vulnerability and keep you updated on progress.
* **Resolution**: Once a fix is verified, a patched version will be released, and we will coordinate public disclosure with you if desired.
* **Credit**: We are happy to publicly acknowledge your contribution in release notes or security advisories (unless you prefer to remain anonymous).
